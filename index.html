Processing Foundation Mission

The most radical futures are built by communities pushed to the margins by dominant tech.

Processing Foundation supports people of all backgrounds in learning how to program and make creative work with code through open-source software, fellowships, and educational resources.

Processing Foundation's Impact

Breaking artists into computer science for 25 years, and we're not done.

The journey began when Casey Reas and Ben Fry developed Processing Java in 2001, making coding free and accessible to artists. Since then, we've grown into a non-profit supporting the Processing ecosystem.

Fellowship Track 01

GAMING THE SYSTEM

The Gaming the System track will support 3 fellows to develop a 2D game design toolkit using p5.js.

Guided by fellows, students will enhance p5.js features – making 2D physics more accessible to beginners. Fellows will create open-access tutorials and templates, and support students with game development through a summer intensive.

Community partners

Fellowship Track 02

HEALING THROUGH PLAY

The Healing Through Play track will support 3 fellows to introduce physical inputs and ouputs to beginners through an interactive art toolkit.

With support from fellows, youth will develop and enhance Processing Python features making pose recognition and voice recognition more robust and beginner-friendly. Fellows will create open-access tutorials and templates, and support students with interactive installation artwork.
